# Artefacto Digital - Music Archive

Para o Artefacto Digital, sabia que queria trabalhar algo onde pudesse incluir música e uma experiência interativa. Música é uma das minhas maiores paixões, sou ávida colecionadora de vinis e procuro sempre conhecer novos artistas e explorar mais estilos musicais. Para o input escolhi a imagem relacionada com o som, daí também querer colocar as frequências dos db associadas ao ritmo da música. Na referência/expressão acabo por escolher o ASCII (tendo usado ativamente esta ferramenta para a criação das capas: https://www.asciiart.eu/image-to-ascii). Encaro o meu artefacto digital como um arquivo de música (daí ter colocado Music Archive no canto de cada página). Acaba por ser uma forma de descobrir factos sobre algumas bandas, e poder ouvir uma música de cada uma delas. Usei bastante o auxílio do ChatGPT para fazer este projeto, foi um processo muito demorado com imensas tentativa-erro, constantemente a inspecionar o código e corrigir erros, testar, corrigir, testar, corrigir até funcionar. Para além disso, eu queria compreender o código que tinha à minha frente (sendo gigante, algumas funções foram mais difíceis de entender). Em todas as decisões tomadas tive em conta a experiência do utilizador. Também acrescentei uma fonte ao meu index.html, algo que antes não sabia fazer.
